## 작업: 영상 패널 "트래킹" 섹션 — 포인트 모션 트래킹 + AE 내보내기

### 요구사항 (사용자 확정)

- 버튼을 누르고 영상의 한 지점을 클릭 → 그 특징점을 전체 영상에 걸쳐 추적하는

- opencv 4.13.0에는 레거시 CSRT/KCF 트래커가 없음 →

## 작업 2: 트래킹 드리프트 수정 — 자동 견고화 + 수동 보정

### 문제
추적점이 비슷한 텍스처(다른 물체/배경)와 겹치면 LK가 엉뚱한 특징에 들러붙어
원래 점으로 못 돌아오고 잘못된 위치를 계속 따라감(드리프트). 원인: LK는 프레임 간
상대 이동만 추적하고 외형 기억이 없으며, 기존 `_track_worker`는 `status==0`(완전
실패)만 검사하고 전후방 일관성/`err`을 무시.

### 사용자 확정
- 자동 견고화 + 수동 보정 (둘 다)
- 재추적 범위: 보정 프레임 → 앞쪽 끝까지(덮어쓰기), 이전 프레임 유지

### 구현 (src/video_panel.py, exporter 변경 없음)
- 견고화 헬퍼 추출: `_snap_to_corner`(코너 스냅 함수화), `_extract_template`(패치),
  `_patch_ncc`(`matchTemplate TM_CCOEFF_NORMED`), `_lk_track`(공용 코어).
- `_lk_track` 검증: ① LK status ② **전후방 오차(FB error)** j→i 역추적이 출발점으로
  못 돌아오면(>1.5px) 중단 — Median Flow 방식, 겹침/가림 핵심 검출 ③ 범위 ④ **템플릿
  NCC** < 0.55면 중단(다른 물체로 점프 시 외형 불일치). 통과하는 동안만 위치 누적,
  실패 시 그 방향 중단 → 잘못된 위치를 남기지 않음.
- `_track_worker`를 `_lk_track`(step ±1) 호출로 단순화. `math` import 추가.
- 수동 보정: 상태 `_track_correct_id`(pick 모드와 상호배타). 목록 행에 `✎` 버튼 →
  `_start_correct(tid)`로 보정 모드 진입. `_on_track_click`에 보정 분기 추가.
  `_correct_worker`: 보정 지점에서 새 템플릿 재추출 → 앞쪽 끝까지 재추적 →
  `pos` 병합(frame<corr 유지, corr 및 이후 덮어씀). `_track_finish_ui`에서 리셋.

### 작업 4-1: 네점 추적 중 모서리가 도중에 사라지는 문제 분석 + 평면 추적 수정

#### 요구사항
- "4개의 점 추가할때 도중에 점이 사라지는데 왜 그런지 분석해서 수정해줘"

#### 원인 분석 (진단 스크립트 `/tmp/diag_quad.py`)
- 모서리별 독립 LK 추적은 클릭 지점이 **저텍스처 영역**에 떨어지면
  `cv2.calcOpticalFlowPyrLK`가 즉시 status=0 반환 → 그 모서리만 추적 실패.
- NCC를 꺼도(`ncc_thresh=-1`), 임계값을 완화해도(`fb 3.0/ncc 0.2`) 4점 중 3점이
  첫 프레임에서 사망. "4코너 모두 존재 프레임 = **1/139**".
- 결론: 임계값 문제가 아니라 **모서리 코너 자체가 추적 불가능한 지점**일 수 있음.
  코너핀은 4점이 한 평면처럼 **강체로 움직여야** 자연스러움.

#### 수정 (평면 호모그래피 추적)
- `_track_plane_dir(grays, corners0, origin, step, progress)` 신규:
  사각형 **내부**의 강한 특징점들(`goodFeaturesToTrack` mask=fillPoly, 최대200)을
  LK로 추적 → FB오차로 생존점 필터 → 프레임마다 `findHomography(RANSAC)` →
  `perspectiveTransform`으로 origin 4모서리를 투영. 모서리는 개별 추적이 아니라
  평면 변환으로 산출되어 **절대 단독으로 사라지지 않음**. 생존점<6 또는 H실패 시 중단.
- `_quad_worker` 재작성: 전진+후진 평면 추적 호출. 내부 특징점<8(텍스처 부족)이면
  `None` 반환 → 기존 `_track_group`(모서리별) **폴백**. 진행률 상태표시.

#### 테스트 (WSL2 실제 영상 `/tmp/verify_plane.py`)
