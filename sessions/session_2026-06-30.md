# 세션: 2026-06-30

## 작업: 영상 패널 "트래킹" 섹션 — 포인트 모션 트래킹 + AE 내보내기

### 요구사항 (사용자 확정)
- 영상 분석 패널(`src/video_panel.py`, `VideoPanel`)의 **오버레이와 애니화 사이**에
  "트래킹" 접이식 섹션 추가.
- 버튼을 누르고 영상의 한 지점을 클릭 → 그 특징점을 전체 영상에 걸쳐 추적하는
  마커를 렌더링. AE의 포인트 트래커처럼 Position 키프레임으로 내보내기.
- 추적 범위: 클릭 프레임 기준 **양방향(앞→뒤 + 뒤→앞) 전체 영상**.
- 점 개수: **여러 개** — 클릭마다 추가, 점마다 고유 번호/색.
- 내보내기: 트래킹 섹션 내 **전용 "트랙 내보내기" 버튼**.

### 기술 선택
- opencv 4.13.0에는 레거시 CSRT/KCF 트래커가 없음 →
  **`cv2.calcOpticalFlowPyrLK`(Lucas-Kanade 광학 흐름)** 으로 프레임 간 점 추적.
- 클릭 지점 텍스처가 없으면 LK가 즉시 실패(1프레임) → 클릭 주변 30×30 ROI에서
  `cv2.goodFeaturesToTrack`로 **가장 강한 코너에 스냅** 후 추적 (안정성↑).
